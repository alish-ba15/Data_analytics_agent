## 4. User Query & Analytical Approach
**User Question:** *“Which category has the highest average quantity?”*  

**Analytical Steps Implemented in Pandas**
1. **Group‑by** `Category` and compute the mean of `Quantity`.  
2. **Identify** the category with the maximum average using `idxmax()` and `max()`.  
3. **Package** the answer into a one‑row DataFrame (`result`) containing the category name and its average quantity.

---

## 5. Python Analysis Code & Executed Data Output  

```python
# Compute average quantity per category
avg_quantity = df.groupby('Category')['Quantity'].mean()

# Identify the category with the highest average quantity
top_category = avg_quantity.idxmax()
top_average = avg_quantity.max()

# Store the result as a one‑row DataFrame
result = pd.DataFrame({
    'Category': [top_category],
    'Average Quantity': [top_average]
})
```
