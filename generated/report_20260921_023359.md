## 4. User Query & Analytical Approach
- **User Query:** *“Show payment method distribution across regions.”*  
- **Analytical Methodology:**  
  1. **Group** the data by `Location` (region) and `Payment Method`.  
  2. **Count** the number of transactions per combination.  
  3. **Pivot** the counts into a matrix (`Location` rows, `Payment Method` columns).  
  4. **Calculate** row‑wise totals and percentages for a clear distribution view.

---

## 5. Python Analysis Code & Executed Data Output  

### Code
```python
# Count of transactions per payment method for each region (Location)
distribution = (
    df.groupby(['Location', 'Payment Method'])
      .size()
      .unstack(fill_value=0)
)

# Add total transactions per region
distribution['Total'] = distribution.sum(axis=1)

# Compute percentage share per payment method
percentage = distribution.div(distribution['Total'], axis=0).applymap(lambda x: f"{x:.1%}")

distribution.reset_index(inplace=True)
```
