## 4. User Query & Analytical Approach
**User Question:** *“Analyze key trends over time and show period progression.”*  

**Analytical Methodology**
1. **Create a monthly period column** from `Transaction Date`.  
2. **Group by month** and compute:  
   - `Total_Revenue` = sum of `Total Spent`  
   - `Transaction_Count` = count of distinct `Transaction ID`  
   - `Avg_Transaction_Value` = mean of `Total Spent`  
   - `Total_Quantity` = sum of `Quantity`  
3. **Sort chronologically** to reveal progression.  

All operations were performed with Pandas, preserving the cleaned data.

## 5. Python Analysis Code & Executed Data Output  

```python
# -------------------------------------------------

# 2️⃣  Ensure the date column is datetime

# -------------------------------------------------
# 3️⃣  Build a monthly period column
# -------------------------------------------------
df_clean['Period'] = df_clean['Transaction Date'].dt.to_period('M')

# -------------------------------------------------
# 4️⃣  Aggregate key metrics by month
# -------------------------------------------------
result = (
    df_clean.groupby('Period')
            .agg(
                Total_Revenue=('Total Spent', 'sum'),
                Transaction_Count=('Transaction ID', 'nunique'),
                Avg_Transaction_Value=('Total Spent', 'mean'),
                Total_Quantity=('Quantity', 'sum')
            )
            .reset_index()
            .sort_values('Period')
)

# -------------------------------------------------
# 5️⃣  Make Period human‑readable
# -------------------------------------------------
result['Period'] = result['Period'].astype(str)

# `result` now holds the monthly trend table
```
