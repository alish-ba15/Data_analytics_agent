## 4. User Query & Analytical Approach
- **User Query (natural language):** *“Show overall percentage distribution across segments.”*  
- **Interpretation:** Compute the share of each **Course** (segment) relative to the total number of students.  
- **Analytical Steps in Pandas:**  

1. Use `value_counts(normalize=True)` on the `Course` column to obtain proportions.  
2. Multiply by 100 and round to two decimal places for readability.  
3. Reset the index to produce a tidy DataFrame with columns `Course` and `Percentage`.  

---

## 5. Python Analysis Code & Executed Data Output  

```python
# -------------------------------------------------
# 1️⃣ Use the cleaned DataFrame (df_clean)
# -------------------------------------------------
# Calculate percentage distribution of students per Course (segment)
result = (
    df_clean['Course']
        .value_counts(normalize=True)      # proportion of total
        .multiply(100)                     # convert to percent
        .round(2)                           # round for readability
        .reset_index()                      # turn into a DataFrame
        .rename(columns={'index': 'Course', 'Course': 'Percentage'})
)

# Display the final table
result
```
