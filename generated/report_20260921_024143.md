## 4. User Query & Analytical Approach
**User Question:** *“Which category has the highest average quantity?”*  

**Analytical Steps Implemented in Pandas**
1. **Group** the data by `Category`.  
2. **Calculate** the mean of `Quantity` for each group.  
3. **Identify** the category with the maximum mean value using `idxmax()`.  

This approach directly answers the question by comparing average quantities across all product categories.

---

## 5. Python Analysis Code & Executed Data Output  

```python
# -------------------------------------------------
# 1️⃣ Compute average quantity per category
# -------------------------------------------------
avg_quantity_by_category = df.groupby('Category')['Quantity'].mean()

# -------------------------------------------------
# 2️⃣ Identify the category with the highest average quantity
# -------------------------------------------------
result = avg_quantity_by_category.idxmax()

# -------------------------------------------------
# 3️⃣ (Optional) Show the top 5 categories for context
# -------------------------------------------------
```
