## 4. User Query & Analytical Approach
**Natural‑language request:** *“Show payment method distribution across regions.”*  

**Analytical methodology:**
1. **Group** the cleaned data by `Location` (region) and `Payment Method`.  
2. **Count** transactions per combination (`size`).  
3. **Calculate** each payment‑method’s share within its region (percentage).  
4. **Sort** for readability (region → descending count).  

The resulting table (`result`) contains:
- `Location`
- `Payment Method`
- `Transaction Count`
- `Percentage` (rounded to two decimals).

---

## 5. Python Analysis Code & Executed Data Output  

```python
# -------------------------------------------------
# 1️⃣ Use the cleaned DataFrame from the validation step
# -------------------------------------------------
df_clean = result.copy()   # `result` already holds the cleaned df

# -------------------------------------------------
# 2️⃣ Compute distribution of payment methods per region
# -------------------------------------------------
counts = (
    df_clean.groupby(['Location', 'Payment Method'])
            .size()
            .reset_index(name='Transaction Count')
)

# Total transactions per region
totals = counts.groupby('Location')['Transaction Count'].transform('sum')

# Percentage share within each region
counts['Percentage'] = (counts['Transaction Count'] / totals * 100).round(2)

# Sort for readability
result = (
    counts.sort_values(['Location', 'Transaction Count'],
                       ascending=[True, False])
          .reset_index(drop=True)
)

# `result` now holds the final output
```
