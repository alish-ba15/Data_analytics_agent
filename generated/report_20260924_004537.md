## 4. User Query & Analytical Approach
- **User query:** *“Show overall percentage distribution across segments.”*  
- **Interpretation:** Compute each **Category’s** share of the **total spend** across the entire dataset.  
- **Methodology:**  
  1. **Group** data by `Category` and **sum** `Total Spent`.  
  2. **Calculate** overall spend (sum of all categories).  
  3. **Derive** percentage = (category spend / overall spend) × 100.  
  4. **Sort** descending for readability.  

All operations are performed with Pandas, producing a tidy DataFrame named `result`.

---

## 5. Python Analysis Code & Executed Data Output  

```python
# -------------------------------------------------
# 1️⃣ Group by Category & sum Total Spent
category_totals = df.groupby('Category')['Total Spent'].sum()

# 2️⃣ Compute overall total spend
overall_total = category_totals.sum()

# 3️⃣ Calculate percentage contribution per Category
percentage = (category_totals / overall_total * 100).reset_index(name='Percentage')

# 4️⃣ Sort descending for readability
percentage = percentage.sort_values('Percentage', ascending=False).reset_index(drop=True)

# 5️⃣ Store final output
result = percentage
# -------------------------------------------------
```
