## 4. User Query & Analytical Approach
**Natural‑language question:**  
> *Which customer segment yields the highest average order value?*

**Analytical methodology**
1. **Use the cleaned DataFrame** (`df_clean`).  
2. **Group** the data by `Customer Segment`.  
3. **Aggregate** the `Total Spent` column with the mean function → average order value per segment.  
4. **Identify** the segment with the maximum average.  
5. **Return** that segment and its average order value in a tidy `Series` (or one‑row `DataFrame`).  

---

## 5. Python Analysis Code & Executed Data Output  

```python
# -------------------------------------------------
# 1️⃣ Use the cleaned DataFrame from the previous step
# -------------------------------------------------
df_clean = result.copy()          # `result` holds the cleaned data from the validation step

# -------------------------------------------------
# 2️⃣ Compute average order value per customer segment
# -------------------------------------------------
avg_order_by_segment = df_clean.groupby('Customer Segment')['Total Spent'].mean()

# -------------------------------------------------
# 3️⃣ Identify the segment with the highest average order value
# -------------------------------------------------
result = avg_order_by_segment.sort_values(ascending=False).head(1)

# -------------------------------------------------
# 4️⃣ (Optional) Convert to a readable DataFrame for reporting
# -------------------------------------------------
result = result.reset_index().rename(columns={'Total Spent': 'Average Order Value'})
```
