## 4. User Query & Analytical Approach
- **User query:** *“Analyze time‑series trends over date/time columns and display overall progression.”*  
- **Analytical methodology:**  
  1. **Ensure** `Transaction Date` is a proper datetime.  
  2. **Group** transactions by month using `pd.Grouper(freq='MS')`.  
  3. **Aggregate**:  
     - `Total_Spent` → sum of `Total Spent` per month.  
     - `Transaction_Count` → count of `Transaction ID` per month.  
  4. **Sort** chronologically and rename the date column to `Month`.  
  5. **Store** the final time‑series table in `result`.

## 5. Python Analysis Code & Executed Data Output  

```python
# -------------------------------------------------
# Time‑series aggregation of monthly spend & volume
# -------------------------------------------------
# (Assumes the cleaned DataFrame is already in `df`)

# 1. Ensure the date column is datetime
df['Transaction Date'] = pd.to_datetime(df['Transaction Date'])

# 2. Aggregate by month (month‑start frequency)
result = (
    df.groupby(pd.Grouper(key='Transaction Date', freq='MS'))
      .agg(
          Total_Spent=('Total Spent', 'sum'),
          Transaction_Count=('Transaction ID', 'count')
      )
      .reset_index()
      .sort_values('Transaction Date')
)

# 3. Rename for clarity
result = result.rename(columns={'Transaction Date': 'Month'})
```
