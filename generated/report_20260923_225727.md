## 4. User Query & Analytical Approach
**User question**: *“Show percentage distribution and transaction breakdown across primary group columns.”*  

**Analytical methodology**  

1. **Identify primary categorical columns**: `Category`, `Payment Method`, `Location`, `Discount Applied`.  
2. **Compute for each column**:  
   - Transaction count per distinct value (including `NaN`).  
   - Percentage of total transactions.  
   - Sum of `Total Spent` per value.  
3. **Combine** the per‑column breakdowns into a single DataFrame (`result`).  

All operations were performed with pandas (`value_counts`, `groupby`, arithmetic on the total row count).  

---

## 5. Python Analysis Code & Executed Data Output  

### Code
```python
# Define the primary categorical columns to analyse
primary_cols = ['Category', 'Payment Method', 'Location', 'Discount Applied']

# List to collect per‑column breakdown DataFrames
breakdowns = []

# Total number of transactions for percentage calculation
total_txns = len(df)

for col in primary_cols:
    # Count transactions per category (including NaN)
    counts = df[col].value_counts(dropna=False)
    # Percentage of total transactions
    perc = counts / total_txns * 100
    # Sum of Total Spent per category
    spent = df.groupby(col)['Total Spent'].sum().reindex(counts.index)

    # Assemble the breakdown for this column
    temp = pd.DataFrame({
        'Group': col,
        'Group Value': counts.index,
        'Transaction Count': counts.values,
        'Percentage': perc.values,
        'Total Spent': spent.values
    })
    breakdowns.append(temp)

# Concatenate all breakdowns into a single result DataFrame
result = pd.concat(breakdowns, ignore_index=True)
```

## 6. Key Insights & Strategic Recommendations  

### Insights  
- **Category balance**: No single category dominates; marketing can target any of the top categories with similar ROI expectations.  
- **Payment method parity**: Cash, digital wallets, and credit cards are used almost equally. Infrastructure for all three should be maintained.  
- **Online vs. In‑store**: Online sales edge out in‑store by ~1 % of transactions, indicating a healthy e‑commerce channel that could be further expanded.  
- **Discount usage**: Roughly one‑third of purchases apply a discount, another third do not, and a third lack discount data. This suggests an opportunity to clean the discount field and to analyze the impact of discounts on spend.  

### Recommendations  
1. **Enhance discount data capture** – ensure the `Discount Applied` field is consistently populated to enable precise profitability analysis.  
2. **Leverage the online growth** – invest in digital marketing and logistics to convert the modest online lead into a larger share of total sales.  
3. **Maintain multi‑payment support** – given the near‑equal split, removing any payment option could alienate ~33 % of customers.  
4. **Category‑specific promotions** – because categories are evenly distributed, rotating promotional budgets across categories can keep overall sales stable while testing effectiveness.
