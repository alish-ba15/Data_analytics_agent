## 4. User Query & Analytical Approach
- **Natural‑language question:** *“Show payment method distribution across regions.”*  
- **Analytical methodology:**  
  1. **Group** the data by `Location` (region) and `Payment Method`.  
  2. **Count** transactions per combination.  
  3. **Calculate** each method’s percentage share within its region.  
  4. **Sort** for readability.  

The implementation uses only Pandas operations (`groupby`, `size`, `reset_index`, `transform`, `sort_values`).

---

## 5. Python Analysis Code & Executed Data Output  

```python
# Count transactions per location and payment method
counts = (
    df.groupby(['Location', 'Payment Method'])
      .size()
      .reset_index(name='Count')
)

# Compute percentage within each location
counts['Percent'] = (
    counts['Count'] / counts.groupby('Location')['Count'].transform('sum') * 100
).round(2)

# Sort for readability
result = counts.sort_values(['Location', 'Count'], ascending=[True, False]).reset_index(drop=True)
result
```
