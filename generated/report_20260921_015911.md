## 4. User Query & Analytical Approach
- **User question:** *“What is the average transaction total by location?”*  
- **Analytical methodology:**  
  1. **Group** the cleaned data by the `Location` column.  
  2. **Aggregate** the `Total Spent` field using the mean function.  
  3. **Rename** the resulting column to `Average Transaction Total` for clarity.  
  4. **Return** a tidy DataFrame with one row per location.

---

## 5. Python Analysis Code & Executed Data Output  

```python
# Calculate average transaction total per location
result = (
    df.groupby('Location', as_index=False)['Total Spent']
      .mean()
      .rename(columns={'Total Spent': 'Average Transaction Total'})
)

# `result` now holds the final answer
```
