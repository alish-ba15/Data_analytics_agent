## 4. User Query & Analytical Approach  

**User Question:**  
> *“What are the top 5 product categories by total revenue?”*  

**Analytical Methodology**  

1. **Group** the cleaned data by the `Category` column.  
2. **Aggregate** the `Total Spent` values using `sum()` to compute total revenue per category.  
3. **Sort** the aggregated results in descending order of revenue.  
4. **Select** the first five rows (`head(5)`) to obtain the top‑5 categories.  

All operations are performed with Pandas, preserving the original `df` and using the cleaned `result` only for downstream reporting.

---

## 5. Python Analysis Code & Executed Data Output  

```python
# Compute total revenue per category and retrieve the top 5 categories
result = (
    df.groupby('Category')['Total Spent']
      .sum()
      .reset_index(name='Total Revenue')
      .sort_values('Total Revenue', ascending=False)
      .head(5)
)

# The variable `result` now holds the final table
```
