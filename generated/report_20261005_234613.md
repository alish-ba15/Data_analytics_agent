## 4. User Query & Analytical Approach
- **User Question:** *“What are total sales by product category?”*  
- **Analytical Methodology:**  
  1. **Group** the data by the `Category` column.  
  2. **Aggregate** the `Total Spent` values using a sum to compute total sales per category.  
  3. **Rename** the aggregated column to `Total Sales` for clarity.  
  4. **Sort** the result in descending order of sales for easy interpretation.  

---

## 5. Python Analysis Code & Executed Data Output  

### Code
```python
# Aggregate total sales per product category
result = (
    df.groupby('Category', as_index=False)['Total Spent']
      .sum()
      .rename(columns={'Total Spent': 'Total Sales'})
)

# Sort categories by descending sales
result = result.sort_values('Total Sales', ascending=False).reset_index(drop=True)
```
