## 4. User Query & Analytical Approach
**User Query:** *“Show payment method distribution across regions.”*  

**Analytical Methodology**
1. **Group** the data by `Location` (region) and `Payment Method`.  
2. **Count** the number of transactions per combination.  
3. **Calculate** the percentage share of each payment method within its region.  
4. **Sort** results for readability (by region, then descending transaction count).  

The approach yields a clear, region‑level breakdown of payment‑method usage.

---

## 5. Python Analysis Code & Executed Data Output  

```python
# -------------------------------------------------
# 1️⃣ Group by region (Location) and payment method
# -------------------------------------------------
counts = (
    df.groupby(['Location', 'Payment Method'])
      .size()
      .reset_index(name='Transaction_Count')
)

# -------------------------------------------------
# 2️⃣ Compute total transactions per region
# -------------------------------------------------
totals = counts.groupby('Location')['Transaction_Count'].transform('sum')

# -------------------------------------------------
# 3️⃣ Add percentage column (rounded to 2 decimals)
# -------------------------------------------------
counts['Percentage'] = (counts['Transaction_Count'] / totals * 100).round(2)

# -------------------------------------------------
# 4️⃣ Sort for presentation
# -------------------------------------------------
result = counts.sort_values(['Location', 'Transaction_Count'],
                            ascending=[True, False])
```
