## 4. User Query & Analytical Approach
- **User Question:** *“What are total sales by product category?”*  
- **Analytical Methodology:**  
  1. **Group** the cleaned data by `Category`.  
  2. **Aggregate** the `Total Spent` column using `sum()` to compute total sales per category.  
  3. **Rename** the aggregated column to `Total Sales`.  
  4. **Sort** the result in descending order of `Total Sales` for easy ranking.  

All operations were performed with Pandas, preserving the original dataset.

## 5. Python Analysis Code & Executed Data Output  

### Code
```python
# Calculate total sales by product category
result = (
    df.groupby('Category', as_index=False)['Total Spent']
      .sum()
      .rename(columns={'Total Spent': 'Total Sales'})
      .sort_values('Total Sales', ascending=False)
)
```
