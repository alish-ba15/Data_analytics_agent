## 4. User Query & Analytical Approach
**User question:**  
> “Generate a complete PowerBI‑style executive dashboard overview with primary category breakdown and trends.”

**Analytical methodology (implemented in Pandas):**
1. **Category breakdown** – grouped by `Category` to compute total spend, distinct transaction count, average spend, and average quantity.  
2. **Monthly trend** – extracted calendar month from `Transaction Date`, then summed spend and counted distinct transactions per month.  
3. **Payment‑method distribution** – counted occurrences of each `Payment Method`.  
4. **Discount usage rate** – calculated the mean of `Discount Applied` per category (interpreted as % of transactions with a discount).  
5. **Top‑5 revenue items** – summed `Total Spent` per `Item` and selected the five highest.  

All results were converted to JSON‑serialisable dictionaries for easy downstream consumption.

## 5. Python Analysis Code & Executed Data Output  

### Code
```python
# Convert the transaction date column to datetime (working on a copy)
df_dates = df.copy()
df_dates['Transaction Date'] = pd.to_datetime(df_dates['Transaction Date'])

# 1. Category breakdown
category_summary_df = (
    df_dates.groupby('Category')
    .agg(
        total_spent=('Total Spent', 'sum'),
        transaction_count=('Transaction ID', 'nunique'),
        avg_spent=('Total Spent', 'mean'),
        avg_quantity=('Quantity', 'mean')
    )
    .reset_index()
)

# 2. Monthly trends (by calendar month)
df_dates['Month'] = df_dates['Transaction Date'].dt.to_period('M').astype(str)
monthly_trend_df = (
    df_dates.groupby('Month')
    .agg(
        total_spent=('Total Spent', 'sum'),
        transactions=('Transaction ID', 'nunique')
    )
    .reset_index()
    .sort_values('Month')
)

# 3. Payment method distribution (overall)
payment_method_distribution_df = (
    df_dates['Payment Method']
    .value_counts()
    .reset_index()
    .rename(columns={'index': 'payment_method', 'Payment Method': 'count'})
)

# 4. Discount usage rate per category
discount_rate_by_category_df = (
    df_dates.groupby('Category')['Discount Applied']
    .mean()
    .reset_index()
    .rename(columns={'Discount Applied': 'discount_rate'})
)

# 5. Top 5 items by revenue
top_items_df = (
    df_dates.groupby('Item')['Total Spent']
    .sum()
    .nlargest(5)
    .reset_index()
    .rename(columns={'Total Spent': 'total_spent'})
)

# Assemble JSON‑serialisable result
result = {
    'category_summary': category_summary_df.to_dict(orient='records'),
    'monthly_trend': monthly_trend_df.to_dict(orient='records'),
    'payment_method_distribution': payment_method_distribution_df.to_dict(orient='records'),
    'discount_rate_by_category': discount_rate_by_category_df.to_dict(orient='records'),
    'top_items': top_items_df.to_dict(orient='records')
}
```
