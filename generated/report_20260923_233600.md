## 4. User Query & Analytical Approach  

**User question**  
> “Generate a complete PowerBI‑style executive dashboard overview with primary category breakdown and trends.”

**Analytical methodology**  

1. **Category‑level summary** – `groupby('Category')` to compute:  
   - Total revenue (`sum Total Spent`)  
   - Total quantity (`sum Quantity`)  
   - Average price per unit (`mean Price Per Unit`)  
   - Number of distinct transactions (`nunique Transaction ID`)  
   - Discount usage rate (`mean Discount Applied`)  

2. **Monthly revenue & transaction trend** –  
   - Create a `Month` period (`dt.to_period('M')`)  
   - Aggregate revenue and distinct transaction count per month  

3. **Payment‑method distribution** – `value_counts()` on `Payment Method`.  

4. **Overall discount rate** – overall mean of `Discount Applied`.  

All results are converted to JSON‑serialisable structures for downstream visualisation.

## 5. Python Analysis Code & Executed Data Output  

### 5.1 Code  

```python
# Ensure the date column is datetime
df['Transaction Date'] = pd.to_datetime(df['Transaction Date'])

# 1. Category‑level summary
category_summary = (
    df.groupby('Category')
      .agg(
          total_revenue=('Total Spent', 'sum'),
          total_quantity=('Quantity', 'sum'),
          avg_price_per_unit=('Price Per Unit', 'mean'),
          transaction_count=('Transaction ID', 'nunique'),
          discount_rate=('Discount Applied', 'mean')
      )
      .reset_index()
)

# 2. Monthly revenue & transaction trend
monthly_trend = (
    df.assign(Month=df['Transaction Date'].dt.to_period('M'))
      .groupby('Month')
      .agg(
          monthly_revenue=('Total Spent', 'sum'),
          monthly_transactions=('Transaction ID', 'nunique')
      )
      .reset_index()
      .astype({'Month': 'str'})
)

# 3. Payment method distribution
payment_method_distribution = (
    df['Payment Method']
      .value_counts()
      .reset_index()
      .rename(columns={'index': 'Payment Method', 'Payment Method': 'Count'})
)

# 4. Overall discount usage rate
overall_discount_rate = df['Discount Applied'].mean()

# Package results
result = {
    "category_summary": category_summary.to_dict(orient="records"),
    "monthly_trend": monthly_trend.to_dict(orient="records"),
    "payment_method_distribution": payment_method_distribution.to_dict(orient="records"),
    "overall_discount_rate": float(overall_discount_rate)
}
```
